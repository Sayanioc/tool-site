Control Valve Cv / Kv Calculator (Liquid)

What this calculator does

It calculates the flow coefficient (Kv or Cv) a control valve needs to pass a given liquid flow at a given pressure drop, and checks the drop against the choked-flow limit. Pick a valve whose rated Cv gives roughly 20–80 % travel at the design flow.

Formula (IEC 60534-2-1, incompressible fluids)

Kv = Q × √( (ρ1/ρ0) / Δp )            Q in m³/h, Δp in bar   (N1 = 1)
Cv = Q / 0.865 × √( (ρ1/ρ0) / Δp )    = 1.156 × Kv           (N1 = 0.865)
US form: Cv = gpm × √( SG / Δp[psi] )

Choked-flow check:
FF        = 0.96 − 0.28 × √(pv / pc)
Δp_choked = FL² × (p1 − FF × pv)       (Fp = 1)
Valid only if Δp < Δp_choked

Worked example (IEC 60534-2-1 Annex D)

Water at 90 °C (ρ1 = 965.4 kg/m³, pv = 0.701 bar a, pc = 221.2 bar a), Q = 360 m³/h, p1 = 6.8 bar a, p2 = 2.2 bar a, globe valve FL = 0.90. FF = 0.96 − 0.28√(0.701/221.2) = 0.944. Δp_choked = 0.81 × (6.8 − 0.944 × 0.701) = 4.97 bar > Δp = 4.6 bar, so the flow is not choked. Kv = 360 × √(0.9654 / 4.6) = 165, Cv = 191.

Limits – read before use

  • Non-choked, turbulent flow only. If Δp ≥ Δp_choked the flow is choked (cavitating or flashing); the valve capacity is limited and the full IEC procedure plus a cavitation/noise assessment is needed.
  • Piping geometry factor Fp = 1: valve the same size as the pipe, no reducers. With reducers the required C is higher.
  • Reynolds number factor FR = 1: valid for low-viscosity liquids (water, light hydrocarbons). Viscous liquids need the IEC Reynolds correction.
  • Single-phase Newtonian liquid. Not for gas, steam, two-phase or slurries.

Common mistakes

  • Using gauge pressures in the choked-flow check – p1, pv and pc must be absolute.
  • Sizing at maximum flow only; check minimum and normal flow as well for rangeability.
  • Mixing Cv and Kv (Cv = 1.156 Kv).
  • Using the pump shut-off pressure or a guessed Δp instead of the system Δp at the design flow.

Standard

IEC 60534-2-1:2011 (ISA-75.01.01) Industrial-process control valves – Part 2-1: Flow capacity – Sizing equations for fluid flow under installed conditions.
