Thermocouple Calculator (°C ↔ mV)

Convert hot-junction temperature to thermocouple voltage and back for types K, J, T, E, N, R, S and B, using the NIST ITS-90 reference functions with cold-junction compensation.

0 °C = table (ice point) reference. Enter the terminal temperature to match what a meter actually reads.

What this calculator does

A thermocouple produces a voltage that depends on the temperature difference between its hot (measuring) junction and its cold (reference) junction – usually the transmitter or card terminals. This calculator gives the voltage a meter would read for a given process temperature and terminal temperature, and the process temperature for a measured voltage. Use it to set a mV source when calibrating, or to check a reading with a multimeter.

Formula

E(t)   = Σ cᵢ·tⁱ          (+ a₀·exp[a₁(t − a₂)²] for type K, t ≥ 0 °C)
E_meas = E(t_hot) − E(t_cold)               (what the meter reads)
t_hot  = E⁻¹( E_meas + E(t_cold) )          (cold-junction compensation)

E is in mV with the reference junction at 0 °C; cᵢ and aᵢ are the NIST ITS-90 coefficients for each type and temperature sub-range. The inverse is solved numerically from E(t), so converting back and forth is exact to better than 0.000001 °C (the NIST inverse polynomials are approximations with up to ±0.06 °C error).

Worked example

Type K, process 100 °C, transmitter terminals at 25 °C. E(100) = 4.096 mV, E(25) = 1.000 mV, so a meter at the terminals reads 4.096 − 1.000 = 3.096 mV. Conversely, if you read 3.096 mV with terminals at 25 °C: 3.096 + 1.000 = 4.096 mV → 100 °C. Simply converting 3.096 mV with the 0 °C table would give 75.9 °C – a 24 °C error.

Ranges (NIST ITS-90 reference functions)

K −270…1372 °C   J −210…1200 °C   T −270…400 °C   E −270…1000 °C
N −270…1300 °C   R −50…1768.1 °C  S −50…1768.1 °C  B 0…1820 °C (mV→°C from 50 °C)

Practical sheath and wire limits are usually much lower than these – check the sensor datasheet. Type B output is almost zero and double-valued below 50 °C, so its reverse conversion starts at 50 °C.

Common mistakes

  • Ignoring the cold junction: converting terminal mV with the 0 °C table. Always add E(t_cold).
  • Adding temperatures instead of voltages (t_hot ≠ t_from_mV + t_cold, because E(t) is non-linear).
  • Wrong extension/compensating cable or reversed polarity (the red lead is negative in ANSI colour codes; IEC 60584-3 uses colours by type with a white negative).
  • Copper wire between the thermocouple and the CJC point moves the reference junction.
  • Using type K in reducing atmospheres around 800–1050 °C (green rot) or type J above 760 °C (magnetic transformation) – both cause drift.

Standards

  • NIST Monograph 175 (1993) and NIST ITS-90 Thermocouple Database (SRD 60) – reference functions and coefficients.
  • IEC 60584-1:2013 – EMF specifications and tolerances (same reference functions).
  • ASTM E230 – standard specification and temperature-EMF tables.
