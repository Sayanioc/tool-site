What this calculator does

It converts between temperature and resistance for industrial platinum resistance thermometers (Pt100, Pt500, Pt1000 or any R0) with the standard IEC 60751 coefficients. Use it to check a transmitter input with a decade box or simulator, to verify a DCS reading, or to diagnose a suspect RTD with a multimeter.

Formula – IEC 60751 Callendar-Van Dusen

For −200 °C ≤ t < 0 °C:  R(t) = R0 [1 + A·t + B·t² + C·(t − 100)·t³]
For 0 °C ≤ t ≤ 850 °C:   R(t) = R0 [1 + A·t + B·t²]

A = 3.9083 × 10⁻³ °C⁻¹
B = −5.775 × 10⁻⁷ °C⁻²
C = −4.183 × 10⁻¹² °C⁻⁴   (used only below 0 °C)

Inverse (t ≥ 0 °C): t = [−A + √(A² − 4B(1 − R/R0))] / (2B)
Inverse (t < 0 °C):  solved numerically (Newton) to better than 10⁻⁹ °C

Worked example

Pt100 at 100 °C: R = 100 × (1 + 3.9083×10⁻³ × 100 − 5.775×10⁻⁷ × 100²) = 100 × (1 + 0.39083 − 0.005775) = 138.5055 Ω.

A Pt100 measures 110 Ω: t = [−0.0039083 + √(0.0039083² + 4 × 5.775×10⁻⁷ × 0.1)] / (−1.155×10⁻⁶) = 25.68 °C.

Tolerance classes (IEC 60751)

Class AA: ±(0.10 + 0.0017·|t|) °C
Class A:  ±(0.15 + 0.002·|t|) °C
Class B:  ±(0.30 + 0.005·|t|) °C
Class C:  ±(0.60 + 0.01·|t|) °C

Each class is only valid over a temperature range that depends on construction (wire-wound or thin film) – check the sensor datasheet.

Common mistakes

  • Lead-wire resistance in 2-wire connections adds directly: 2 × 0.5 Ω of copper adds ~1 Ω ≈ +2.6 °C on a Pt100. Use 3- or 4-wire, or subtract the measured loop resistance.
  • Using the α = 0.003926 (US/JIS old) or α = 0.00392 curves with IEC 60751 coefficients – confirm the sensor curve on its datasheet.
  • Using linear 0.385 Ω/°C everywhere: at 400 °C the linear estimate is 254.0 Ω vs 247.09 Ω actual (≈ 18 °C error).
  • Self-heating: measuring with a multimeter current that is too high warms the element.

Standard

IEC 60751:2022 Industrial platinum resistance thermometers and platinum temperature sensors (also EN 60751, ASTM E1137 uses the same A, B, C). Temperatures are on ITS-90.
